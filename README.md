# GenshinWords

**提瓦特大陆有太多故事。把喜欢的台词，变成每天愿意打开的英语练习。**

GenshinWords 是一款在本机离线运行的英语学习软件。你可以用《原神》的角色台词和故事背单词，也可以阅读篇章、完成题目、收藏生词，用原石记录自己的学习收获。

主要面向上海中学生。分级阅读以入门、上海中考、上海高考为重点，并延伸至大学英语四、六级。现有词书还包含其他考试词汇，可以按自己的需要选择；词书范围和阅读级别分别管理。

## 设计目标与学习方法

让熟悉的角色和故事提供记忆线索，再通过回忆和练习检查是否记住。建议把学习分成两个阶段：

1. **背单词与自测**：先回忆释义，再看词义、发音和原句；如实评价记忆情况。软件使用 FSRS 复习算法，根据学习记录安排后续复习。学过后再做认义或拼写自测。
2. **阅读与理解**：按自己的级别选择故事，独立完成一篇阅读，再查看得分、答案依据、文本解析和中英原文。题目按篇章特点和级别组织，不要求每篇都考完词书中的所有词。

也可以先浏览喜欢的剧情，遇到本地词库已收录的词就加入收藏。词书学习、收藏词复习与篇章阅读各自记录进度，随时可以切换。

所有学习记录保存在本机，无需注册账号。日常学习、发音、判分和 PDF 导出均可离线使用。

### 首次安装

1. 从下载中心取得安装程序和与之兼容的完整基础素材包 `.gwcontent`。推荐将两个文件放在同一文件夹；也可以用 U 盘带到离线电脑。
2. 运行安装程序，选择安装目录。下一步会先寻找安装程序同目录的基础素材包；确认建议的文件，或点击“浏览”选择其他位置。若同目录有多个候选包，请明确选择所需版本。升级且已配置基础资源时，可选择沿用本机配置。
3. 首次打开 GenshinWords，软件校验并载入安装时选定的素材包。完整素材首次载入可能需要数分钟。选错或文件损坏时可重新选择，也可进入“内容管理”修复。
4. 首次进入学习界面时选择空或荧。以后可在导航栏或“关于”中重新选择。

已有解包版完整资源的用户仍可在 **“内容管理”→“选择资源目录”** 指定该目录，并从原位置直接读取媒体。以后增加词书、素材或阅读，也可以在这里选择包目录载入。

程序与资源分别更新。以后更新软件通常只需安装新版程序，不必重新下载整套素材；资源有新版时，再导入对应内容包。

### 指定本机资源目录

在“内容管理”的“资源目录”中，点击 **“选择资源目录”**。支持两种目录，也可放在同一个目录中：

- **解包资源目录**：目录根部有 `content.db`，以及配套图片、发音等文件。软件直接从这个位置读取媒体，只缓存数据库与必要索引，不重复复制整套媒体。请保留目录，使用移动硬盘时保持盘符和路径可用。
- **资源包目录**：放置 `.gwcontent`、`.gwwords`、`.gwreading`。软件显示扫描结果，确认后把通过检查的包载入本机缓存；后续学习不依赖原包仍在这个目录中。

软件分别显示当前基础资源路径和最近使用的包目录。以后向包目录放入新版本，再点击 **“重新扫描”→“确认载入”**；目录载入会在当前运行中启用，无需重启。它不会监视文件变化或自动联网更新。

逐项检查结果会说明损坏、缺少依赖、编号冲突等问题；未通过的包不会替换可用内容。切换资源保留个人学习记录，未完成阅读仍使用开始作答时的版本。解包资料没有登记包版本时会明确显示“未登记”；对外发布推荐使用有编号和版本号的内容包。详细规则见[资源目录说明](docs/resource-directories.md)。

## 开始学习

### 背单词

1. 在首页选择“当前词书”和学习顺序，可选顺序、乱序或“原神”顺序。
2. 选择本轮数量：**10 / 20 / 50 / 100 / 马拉松**。到期复习和新词共同计入本轮数量；马拉松会持续提供词卡，想休息时点击“结束本次”。
3. 点击“开始复习”，先在心里回忆词义，也可以听英美发音。
4. 点击“显示释义与台词”，查看词义和本地原句。有多个例句时可切换，角色立绘随当前例句更新。
5. 按实际记忆情况选择“忘记了 / 有些困难 / 记得 / 很熟悉”。评分用于安排复习；之后可进入“单词自测”检查记忆。

有些词没有合适的原神例句，仍可通过本地词典释义和自测学习。例句覆盖情况可在“关于”中查看。

### 单词自测

先学习词卡，再从首页或导航栏进入“单词自测”。普通词书提供认义、拼写等检查；可用干扰项不足时会采用拼写形式。答错后可复习，再回来检查。

### 浏览剧情与收藏词

在“剧情”中按章节、任务等浏览本地文本。点击英文单词可以查看释义；本地词库已收录的词可以加入“收藏词表”，同时保存收录时的原句。

收藏词表与其他词书分开，可以独立复习和自测。**收藏词测试只使用收录时保存的句子**，不会为它另找新的阅读材料；重复收藏不会替换第一次保存的来源。阅读交卷后的原文区也支持点词和收藏。

### 分级阅读

1. 进入“分级阅读”，选择适合自己的级别和篇目。
2. 阅读正文，在“答题区”完成本篇题目，再整篇提交。每篇独立判分，不需要完成一整套试卷。
3. 提交后查看本轮得分、正确答案、选项解释、原文依据、篇章结构、重点句和词语解释。
4. 在解答区对照中英原文，也可点词释义、加入收藏。

列表会标记“已做过”和“已全对”；点击“下一篇阅读”时跳过已全对篇目。未提交的答案可作为草稿保留，之后继续。

低级别篇目会按需要为难词添加括注，原神专名解释放在解答区。每篇可导出包含题面与解析的 PDF，便于打印或离线阅读。**提交前导出含答案的 PDF 后，本轮仍可作答得分，但不再领取新的阅读原石。**

## 如何获得原石

原石来自单词自测与阅读答题，两部分相加。它是本机的学习奖励记录，与游戏账户无关。

| 行为 | 奖励规则 |
| --- | --- |
| 在词卡上选择“记得”或“很熟悉” | 保存复习记录，不直接发放原石 |
| 学过的词首次通过单词自测 | 当前词书中该词获得 **1 颗**；收藏词表单独记录 |
| 阅读题首次有效答对 | 该逻辑题获得 **1 颗**，整篇提交后统一结算并播放发放动画 |
| 答错、重复通过已领奖的词或题 | 不扣原石，也不重复发放已领取的奖励 |

例如：本轮阅读答对 4 题，其中 1 题以前已领奖，本轮得分仍计 4 题，但新获得 3 颗原石。以后开新轮答对先前未领奖的错题，仍可获得相应奖励。

在首页点击原石总数，或进入“原石”页面，可以查看单词自测、阅读答题两类数量和来源明细。阅读成绩记录本轮作答结果；更新题包或在另一个包中复用同一道逻辑题，不会重新发奖。

## 增加和更新资源

打开 **“内容管理”**，可查看本机内容的版本、作者、数量、适用程序版本、依赖和使用状态。

| 文件 | 可以增加什么 | 单文件导入何时启用 |
| --- | --- | --- |
| `.gwwords` 词书包 | 从本地词库选词组成的新词书，或词书清单更新 | 导入后重启 |
| `.gwcontent` 素材包 | 基础词库与媒体的完整版本，或双语剧情、书籍、台词及题图增补 | 导入后重启 |
| `.gwreading` 阅读包 | 独立篇目、题目、答案、解析及配套双语原文和题图 | 确认导入后启用 |

可通过上面的资源目录批量载入；也可以逐个导入，操作为 **选择文件 → 查看检查结果 → 确认导入 → 按提示重启**。导入完全离线；来源链接用于署名，不会自动下载缺失的文件。素材包只增加素材，阅读题目需要另行制作阅读包。

- 重复导入同版本同内容时，不重复安装或领奖；同版本内容不同会被拒绝，需作者提升版本号。
- 缺少依赖、程序版本不兼容或文件损坏时，页面会说明原因，原有可用内容继续保留。
- 词书或素材更新不会清空学习记录、收藏、成绩或原石。阅读更新时，未完成轮次继续使用原来的内容版本。
- 显示“待重启”时，关闭并重新打开软件。旧布局资源可能显示“版本未登记”，它不等于资源不存在。

目前没有联网资源商店、包卸载或旧版本自动清理界面。请使用可信的下载渠道，并保留需要的安装文件和内容包。

## 制作与分享自己的内容

**增加词书、素材或已有题型的阅读内容，不需要修改程序代码，也不需要重新构建 EXE。** 内容作者编写 JSON、整理配套文件，再用独立命令校验和打包。

### 准备工具

需要程序源码、Node.js 22.12 或更新版本、PowerShell 7 和文本编辑器。在源码目录运行一次：

```powershell
npm ci
```

安装工具依赖时可能需要联网。之后校验和打包均可在本地完成，不需要启动 Electron；导入则在软件的“内容管理”中完成。所有文本文件请保存为 **UTF-8 无 BOM**。

制作新内容可以自行创建作者目录。修改现有内容时，请从下载中心取得相应的**作者资料**；现有作者原文、题目和媒体不随 GitHub 源码发布。不要仅修改成品包的扩展名或版本字符串。

### 制作词书

词书是本地词库的选词清单，不导入新的单词释义或外部词条。在源码根目录下建立 `my-content/travel-words/`，准备两个文件。

`manifest.json`：

```json
{
  "id": "myname.words.travel",
  "name": "旅途词书",
  "kind": "words",
  "version": "1.0.0",
  "minAppVersion": "1.1.0",
  "author": "你的名字",
  "createdAt": "2026-10-23"
}
```

`data.json`：

```json
{
  "books": [{
    "id": "travel",
    "name": "Travel Words",
    "name_zh": "旅途词书",
    "description": "从本地词库挑选的旅途词语",
    "lemmas": ["journey", "freedom", "pursuit"]
  }]
}
```

把 `myname` 改成自己的命名空间，再选择本地已有的单词。下面命令均从源码根目录运行，`release/` 用于保存生成文件：

```powershell
npm run content:pack -- my-content/travel-words --out release/travel-words.gwwords
npm run content:validate -- release/travel-words.gwwords
```

打包命令会检查作者数据，`content:validate` 校验生成的包文件。导入时，软件还会检查词表是否全部能在本地词库找到。分享后修改选词时，保持包编号和书编号，提升版本号；旧学习记录仍会保留。

### 制作剧情、书籍或台词素材

素材作者目录使用 `manifest.json`、`data.json` 和可选的 `images/`。清单中设置 `kind: "materials"`，填写自己的包编号、名称、版本和作者；数据按 **章节 → 任务 → 台词** 组织，包含稳定编号、英中原文、说话者、来源链接及可选题图。

```powershell
npm run content:pack -- my-content/my-story --out release/my-story.gwcontent
npm run content:validate -- release/my-story.gwcontent
```

所需图片应随包携带。现有英文原句或归属改变时使用新编号，避免旧收藏指向另一条台词。素材结构、完整基础包制作及版本约束见[素材与词书包说明](docs/content-packages.md)。

### 制作阅读理解

阅读作者目录包含包清单、篇目、来源和题图，例如：

```text
my-content/my-reading/
  manifest.json
  units/          每篇的题目、答案、可接受答案和解析
  sources/        完整双语原文、段落与校验值
  images.json     题图清单、出处和校验值
  assets/         实际图片文件
```

先选择适合级别的材料，再设计题目。现有能力包括阅读选择、完形填空、首字母填空、选词填空、句子补全、段落匹配和信息归纳。每篇独立作答和判分。

制作时需核对英中段落映射、挖空位置、标准与可接受答案、逐项解析、难词和重点句。原神材料使用官方双语原文及注明出处的官方图片，题图按 4:1 裁切并设置主体焦点。详细字段和人工复核要求见[阅读包制作说明](docs/reading-packages.md)与[阅读分级方案](docs/reading-plan.md)。

```powershell
npm run reading:validate -- my-content/my-reading
npm run reading:pack -- my-content/my-reading --out release/my-reading.gwreading
npm run reading:validate -- release/my-reading.gwreading
```

已有题型增加篇目，只更新阅读包。新增题型或改变判分能力时，需要先修改并发布新版程序。

### 发布给其他人

1. 为自己的包、词书、篇目和题目分配稳定编号，不占用他人编号。更新使用 `1.0.0`、`1.0.1` 等版本号，不覆盖已经发布的同版本文件。
2. 运行对应的打包和校验命令。词书/素材在打包时检查作者数据，再校验成品；阅读包还可先校验作者目录。机器校验之外，还要人工检查词表、双语、题意、答案、解析和图片出处。
3. 使用隔离测试数据试导入，检查学习、答题、收藏、原石与 PDF；升级包还要检查旧进度和未完成阅读轮次。
4. 计算文件摘要，附上包名、编号、版本、作者、适用程序版本、依赖、内容数量和更新说明：

   ```powershell
   Get-FileHash -Algorithm SHA256 release/my-reading.gwreading
   ```

5. 通过有权使用的下载渠道或 U 盘分享成品包；若希望别人继续修改，同时提供作者 JSON、可分发素材和制作说明。分享前确认所用内容的授权与署名要求。

本项目的现有资源通过独立下载地址分发，**不上传到本项目的 GitHub 仓库或 Release**。内容包不包含个人学习记录；分享内容时不要附带自己的学习数据目录。

阅读题干、答案、选项或英文考查原文发生变化时，应使用新题号；仅修订解析、中文或题图时可保留题号并提升包版本。这样旧成绩仍对应当时的题目，也不会重复发奖。完整规则见[阅读包版本规则](docs/reading-packages.md#更新与编号规则)。

## 修改程序

你也可以从源码调整界面、学习流程、判分或导出功能。项目使用 Electron、React、TypeScript 和 SQLite。

| 目录 | 可以修改的部分 |
| --- | --- |
| `src/renderer/` | 页面、样式和交互 |
| `src/main/` | 内容加载、复习、自测、判分、原石和 PDF |
| `src/shared/`、`src/preload/` | 数据类型与界面调用接口 |
| `scripts/` | 内容制作、校验与构建工具 |

源码运行与构建会生成随应用提供的基础阅读包和词书包。请先从独立下载地址取得作者资源，将基础阅读作者目录放到 `reading-library/base/`、词书作者目录放到 `content-library/word-books/`；如果需要其余现有示例，也从作者资源中取得。只克隆 GitHub 源码不会自动获得这些内容。

```powershell
npm ci
# 使用独立学习目录运行，避免影响日常学习记录
$env:GENSHINWORDS_USER_DATA = Join-Path $env:TEMP 'GenshinWords-dev'
npm run dev
```

开发版启动后也可以在“内容管理”中导入基础素材包。完成程序修改后，在同一开发环境中检查并构建：

```powershell
npm run typecheck
npm run build:win
```

## 备份与常见问题

### 换电脑或备份进度

先关闭软件，再备份两处默认目录；可通过 `Win + R` 输入路径打开：

- `%APPDATA%\genshin-words\`：学习记录、设置、收藏、成绩、原石及阅读版本存档。
- `%LOCALAPPDATA%\GenshinWords\`：导入的基础素材、词书、剧情、版本缓存与资源目录配置。

换机后安装同版本或兼容的新版本程序，再将备份放回新账户的对应位置。恢复前先备份目标电脑已有的数据。**只复制 `progress.db` 不足以保留历史阅读所需的全部内容。** 使用解包资源目录时，还需保留外部原目录；换机后如果路径改变，请在“内容管理”重新指定。

### 首页提示找不到本地内容

进入“内容管理”，检查基础资源目录是否仍可访问，或选择包含完整基础素材包的目录载入。仅有词书或阅读包不能代替基础词库；单文件导入显示“待重启”时，需要重新打开软件。

### 包导入失败或版本不兼容

按页面提示补齐依赖、更新程序或重新取得完整文件。同版本不同内容不能覆盖导入，需要作者发布更高版本。损坏的已安装包可以尝试重新导入同版本的完整文件修复。

### 资源更新后仍显示旧阅读

未完成轮次保留旧题面与答案，避免旧作答被新版重新解释。可以继续完成旧轮，或按页面提示开始新版新轮；原成绩与奖励记录保留。

### 能否导入任意外部单词或自动生成阅读题

当前词书和收藏仅使用本地词库已有词条。素材包增加可阅读的文本，不会自动出题；新增阅读理解需要作者制作阅读包。
