## 范围与限制

- 本次运行了安装包输出目录中的真实 EXE；没有执行 Windows 安装、覆盖升级、卸载或干净虚拟机检查。
- PDF 服务的既有自动回归通过；本轮没有驱动实际 EXE 的系统保存对话框。可选 CDP 打印接口不可用，不能用它代替软件的原生 PDF 导出验收。
- 外部解包媒体需要保持可访问，数据库缓存不等于完整素材备份。WAL 单库超过 256 MiB 需由作者在副本中完成 checkpoint 并转换为 DELETE 模式。
- 尚未提供目录自动监控、在线下载、包卸载或历史缓存自动清理界面。
