# 剧情目录核对

## 本次结果

只读核对 1,678 个源章节，发现 78 组同名标题（219 个章节），其中 23 个同名章节没有对话行。按原始说话人、英文和中文台词及其顺序完全一致的标准，另识别出 5 组同文来源。

完整结果见 chapter-audit.json，可用以下命令从当前资料库重建：

    npm run check:chapters -- --output docs/chapter-audit.json

审计不修改 content.db。原始 source ID、任务和对话图全部保留；同名不意味着可以合并。同文来源也保留各自入口，并标记“同文来源 N 份”。缺少正文的汇总章节没有批量删除。默认浏览隐藏19个带隐藏/测试标记的内部条目，原始记录保留。

## 其他修正与边界

- iq 实际混有委托、教学和世界任务。已确认的教学任务与《宝藏归离》分别归入对应类别；其余未分类 iq 显示“其他任务”，不冒称邀约。
- iq 未核实的版本留空；“Story Quests”等非版本值不参与版本筛选；数字版本与官方Luna罗马数字名称均予保留。来源原值保留为 original_type / original_version。其他类别现有的数字版本尚未逐条人工核实。
- 《画家漂流记》三份源记录按不同段落标记，保留其独立内容；版本3.6可由[B站 Wiki 版本历史](https://wiki.biligame.com/ys/版本历史)核对。
- 《宝藏归离》区分其一和其二，资料依据：[B站 Wiki 其二](https://wiki.biligame.com/ys/宝藏归离（其二）)。
- 已知错误版本所带出的版本题图一并纠正或取消；网页、词卡来源标签和台本 PDF 使用相同的目录层；PDF标题和默认文件名带上分支副标题。
- 未保存筛选时默认显示全部版本；失效的旧分类筛选自动回退，来源回跳不受上次筛选限制。

展示修正集中在 src/main/chapter-catalog.ts。后续继续核验时，应按源 ID 增加有依据的修正，保留资料库原始记录。
