# 视觉资源

## 已确认的 Logo

采用 A 版香槟金配色：暖纸色面部和书页、香槟金轮廓、深蓝阴影。应用导航和首页放在深蓝金边框内；透明边距已裁紧，使小尺寸下的主体更清楚。

- 源图：src/renderer/src/assets/logo.png（本项目生成并经用户确认的图案）。
- 应用图标：resources/icon.png、resources/icon.ico。
- 重建命令：npm run icons:build。
- ICO 内含 16 / 20 / 24 / 32 / 40 / 48 / 64 / 128 / 256 像素图层；便携版与开发窗口沿用同一套图标。
- 生成器仅裁除透明边距、添加框和缩放，不改变已确认图案。

## 原石

使用游戏资源 UI_ItemIcon_201.png，不以通用星号代替。图标通过 Enka.Network 资源镜像取得，来源为 https://enka.network/ui/UI_ItemIcon_201.png，保存在 src/renderer/src/assets/primogem.png。

首页、复习结束、自测奖励、奖励明细与阅读奖励动画复用 Primogem 组件。辉光和星点由低频 CSS 动画提供；系统要求减少动态效果时停止循环动画。所有资源随应用打包，运行时不请求图片网络地址。

来源与校验值见 visual-assets.json。既有官方角色、活动与地域图片的来源仍由资料库 artwork / artwork_scopes 及图片来源记录保存。

## 剧情题图

剧情章节和台词页的题图占满正文区域，采用 4:1 横向裁剪，允许页面纵向滚动。已核实的《龙与山》三支任务使用 5.0 官方宣传图，主体焦点为 x=0.5、y=0.42；不会沿用原库误配的 1.3 版本图。

无头像的说话者在网页和台本 PDF 中显示名字的第一个字母或汉字；头像区域与文本缩进固定，不因头像缺失而移动。空说话者用“旁”，中文字体随应用提供。
