# 架构与学习规则

## 进程与存储

Electron 主进程处理数据库、文件访问、学习调度与 PDF 导出；React 渲染进程通过 preload 暴露的 window.api 调用 IPC。窗口启用 sandbox 和 contextIsolation。发布模式阻止窗口的 HTTP/WebSocket 请求、页面导航和新窗口。

content.db 以只读方式打开，保存词书、单词、词形、双语台词、书籍正文和角色资料。分级阅读从独立`.gwreading`包读取题目、官方双语和题图，不再查询materials.db。包内原文、段落映射、挖空和资源在导入时完整核验；只使用作者已人工核对的英中段落配对。materials.db保留为内容制作和容量审计的来源库。progress.db 独立保存设置、复习、收藏、练习与奖励，并使用 WAL。单词只能引用本地内容库中的 ID；本系统不接入外部词典或在线内容。

## 资源目录与热载入

1.2.0增加resource-directory-config管理只读基础目录、数据库快照和原址媒体版本，resource-directories负责浅层包扫描、预览令牌、依赖顺序和逐包载入。目录路径只由主进程原生选择器取得，渲染进程仅持有短期令牌。基础目录与包目录分别持久化在内容缓存旁，不写入个人学习记录。

解包基础必须包含content.db、materials.db、images/和audio/。预览核验文件校验值、SQL结构、媒体引用和历史编号，数据库缓存为快照，媒体使用版本命名空间从原位置读取。包目录使用现有格式校验与导入器，内容包保存在受管缓存；同ID按最高有效版本选择，冲突、越界和坏包逐项报告。

content-package-store在同一队列中准备候选派生DB、关闭旧内容连接、打开新库并提交注册与目录选择；失败恢复旧选择、旧库与注册。只关闭内容库，不迁移或重建progress.db。未完成阅读仍由原content_revision固定。目录操作可热启用；单文件素材/词书导入仍按待重启流程处理。操作和限制见[资源目录说明](resource-directories.md)。

## IPC 与类型检查

公开接口统一定义在 src/shared/ipc.ts，数据结构定义在 src/shared/models.ts、practice.ts、reading.ts、collection.ts、traveler.ts、reading-package-management.ts 与 rewards.ts。主进程必须实现完整的通道映射，preload 从同一映射建立方法，页面通过唯一的 Window.api 声明调用接口。接口名、参数、返回结构和可空结果均参与编译检查。

- tsconfig.json：主进程、preload 和共享代码，关闭 skipLibCheck。
- tsconfig.renderer.json：页面和共享代码，启用 strict 与 noImplicitAny，关闭 skipLibCheck。
- tsconfig.contracts.json：编译接口反例，防止方法名、参数、返回值、空值处理和 any 泄漏回归。
- tsconfig.tools.json：单独检查 electron.vite.config.ts；仅此配置保留 skipLibCheck，以隔离构建依赖的声明冲突和未安装的可选 SWC 类型。

npm run typecheck 顺序运行以上四项；任何一项失败即停止。Electron 原生 invoke 的无类型返回和动态方法映射限制在桥接边界，业务页面不直接调用它们。npm run test:ipc 检查全部方法与处理通道一一对应，并通过实际处理函数验证读取、收藏、复习、原句测试与奖励。

当前约束是编译期约束，不会自动校验 SQLite 数据、历史 JSON 或运行时传入值。主进程旧数据库与 PDF 内部仍有宽松推断，尚未全局启用 strict；继续开发时应逐步收紧这些实现，并完善入口校验。

## 独立学习范围

考试词书仅包含自身成员。收藏词使用独立表 collected_words，以单词 ID 去重，并使用独立学习范围 __collection__ 保存卡片、练习与奖励。收藏不会增加考试词书的词数，也不会挤占它的新词队列；同词在收藏与考试词书中的进度分别记录。

收藏词表通过导航栏进入，支持搜索、查看原句、回到来源台词或阅读、移除及撤销移除。收藏复习、测试和奖励明细使用 scope=collection 路由，不修改首页所选考试词书。

## 本地剧情与阅读收录

剧情页点词使用支持重音字符、弯引号和连字符的分词规则。渲染进程只向主进程提交台词 ID 和点击词的字符范围。主进程重新读取本地台词，验证完整词边界，再查询本地词库及明确的英美拼写映射；未收录的词不能加入收藏。

主进程定位被点击词所在的英文句子，保存原句快照、目标词范围、原文词形、说话人、章节、任务、台词 ID、该条台词的中文译文与收录时间。英文快照为该句，中文译文保留原台词整条内容。再次点击同一词保留首次来源，不自动添加或更换阅读材料。

阅读收藏只在已交卷或已通过 PDF 进入解析的轮次中开放。页面提交轮次、段号和相对官方英文整段的词范围；主进程重新读取经双语哈希验证的原文，验证完整词边界，通过本地词头/词形及英美拼写映射查词。未收录词不能收藏，也不会写入内容库。

主进程用 Intl.Segmenter 定位点击时所在的英文句子，保存句内字符范围、实际词形、单元、段号、来源链接、题图与时间。阅读收藏的中文参考为对应官方整段，页面标明整段参考，不冒充逐句译文。来源使用 origin=reading；对话来源使用 origin=dialogue，兼容旧记录没有 origin。两种入口调用同一 saveCollectedWord，以 wordId 去重并保留首次来源。

移除采用停用标记，历史原句、复习进度和奖励均保留；撤销或再次收录可恢复。停用期间不进入复习、测试和当前统计，重新启用不会重复发放奖励。

## 复习会话

首页可选择10 / 20 / 50 / 100 / 马拉松，并保存在 studySize。固定数量按到期词和新词的合计计算，优先安排学习/重学状态及记忆保持率较低的到期词，再用新词补足。考试词书的新词顺序由首页设置；收藏词按收录时间从早到晚安排。再次点击“检查到期卡”只补充到期词。

马拉松以20个词为一批连续补充，直到用户结束或当前没有可学习的卡。已出现的新词不重复补入；已经复习的词仅在FSRS实际到期后允许再次出现，保留短期复习能力。结束时显示实际复习次数与不同单词数。session:next 校验批次数量与排除ID；旧 session:build 仅作为兼容接口保留。

FSRS 将“忘记了 / 有些困难 / 记得 / 很熟悉”转成下一次复习时间。评分使用事务及请求标识防止重复提交；新请求同时绑定评级，未确认时只重试原选择。批次读取失败保留原模式与本轮进度供重试，短期到期提示按每词最新结果更新。复习例句切换只在显示释义后出现，立绘和角色名随当前例句同步切换。

收藏词复习显示本地释义、发音和已保存的收录原句，不另行检索其他例句。缺少来源的旧收藏仍可复习本地词义和发音。

## 测试

先选择已经复习过的单词（cards.reps > 0），再生成测试。默认按出题次数从少到多轮转；同次数下优先尚未练习正确的词、到期词和较早出题的词。次数在生成时保存，跳过或重启也会继续轮转。可通过“检查刚复习的词”、收藏词表或奖励明细检查指定词。

### 考试词书

每轮自测一个词。默认英文认义：显示英文单词，收起词卡释义，用当前词书的本地释义组织四选一；优先同词性，过滤重复与包含词义的选项。可切换重点拼写。可用干扰项不足时使用词义或听音拼写，释义与发音均缺失时提供字母重排，保证每词有检查路径。

自测与阅读分开：普通词书自测不再截取篇章挖词。原书籍/台词定位工具保留用于资料覆盖审计与收藏原句测试，不承担分级阅读命题。建议每学 5–8 词回测一组，目前为页面提示，未设置整本词书完成门槛。

### 收藏词表

仅从该词保存的收录原句生成填空，保留整句，不读取其他书籍、台词例句或替换为词义题。被点击的原文词形必须挖空；句内已识别的目标词重复出现也一并挖空。题面标明“收录时原句”。

没有有效来源快照的旧收藏暂不进入测试队列，指定测试时明确提示补齐来源，不阻塞其他词出题。在本地剧情或已开放的阅读解析中重新点选该词即可保存来源并启用测试。

### 判分与记录

拼写统一大小写、Unicode 规范形式、空白及部分引号/连字符。普通词书检查词头；收藏原句要求正确的原文词形。英美变体使用明确映射；例如 analysed / analyzed 均可，但过去式空格不能填 analyse，名词 analyses 不能填动词 analyzes。

所有空格正确才记为目标词测试正确。出题时公开题面不预先提供正确答案；首次提交后保存并返回判分结果，重复提交不改判、不重复发奖。题目 24 小时后失效，30 天以上的未提交题目在下次出题时清理。

practice_progress 记录轮转情况，word_self_tests 独立保留首测、最新结果与次数。自测失败按 FSRS Again 安排短期再学，通过不额外推进刚评分的词卡。旧版题目记录保留，但 reward_version=1 的题目不能在新规则下继续提交，需重新生成自测。

## 分级阅读

/reading 提供初中基础、上海中考、上海高考、四级、六级五档；默认上海中考。共69个独立阅读练习、381题（原26篇152题、第二批19篇100题保留，第三批新增24篇129题），仍属试行课程，尚未完成考试等值标定。具体篇目与题型见 reading-papers.md。题型包括细读、摘要首字母、一词短答、句子衔接、完形逻辑与段落匹配；封闭式一词短答不代表开放写作能力评估。

阅读目录的completionStatus由已提交的整篇成绩计算：unsubmitted表示尚未完整交卷，completed显示“已做过”，历史任一完整轮次全部答对则perfect显示“已全对”。草稿、仅打开或仅导出PDF不算完成；提交后的热身成绩也属于作答成绩，与是否获得原石无关。不把不同轮次各题的正确记录拼成一次全对。历史组卷成绩只核对本篇所属题号，无需改写原记录或新建轮次。

讲解顶部与底部提供“下一篇阅读”，点击时重新读取持久化状态，在当前级别中按目录顺序循环查找其他未全对篇目，跳过已全对内容；已做但未全对仍可进入。不自动跨级，当前级别没有其他待挑战篇目时提示返回目录或重练。标识保留历史全对记录，重开草稿不清除；所有篇目仍可在目录中手动打开。

### 内容包与版本

作者维护reading-library/base/中的纯JSON和素材，CLI独立校验／打包。reading-package-format负责格式与指纹，reading-package-store管理独立版本存档和原子激活，reading-bank只提供数据兼容门面，不包含作者题目。基础阅读包随安装程序提供，补充包可从阅读目录或内容管理导入，无需联网。大型基础素材以.gwcontent独立发布，现有11本词书各自使用.gwwords；通用管理器负责兼容性、归档、派生数据库与激活：目录载入可在当前运行中启用，单文件素材/词书导入需重启。学习库路径保持。格式、命令和版本规则见[阅读包说明](reading-packages.md)。

reading_sessions.content_revision固定轮次使用的包摘要；旧轮次首次加载时绑定基础版本。判分、解析、点词和PDF始终使用该版本，更新不会重新解释历史成绩；未完成轮次继续旧版，可主动开始新版新轮。收藏与原石来源快照保留，稳定逻辑题号跨版本、跨包只奖励一次。旧篇号、旧目录和题号定位保留；新版本删去的篇目仍可通过历史链接读取存档。

包文件、按摘要命名的图片缓存及registry在reading-packages/中，独立于progress.db。预览后确认时重新核验文件摘要，检查活跃及历史编号冲突；准备资源后原子切换，失败不公布新库。损坏补充包单独报错，其他包继续可用；历史版本不自动清理。

### 整篇交卷

阅读题面使用经校验的英文选段与段号；完形、首字母、选词和选句按精确偏移挖空，不在题面暴露被挖去的原文。每次只打开一篇阅读，本篇题目全部完成后一次提交，不逐题检查、提示或纠错。每题1分：score=correct，maxScore=total=本篇题数。阅读页和 PDF 展示本轮得分，不展示历史首答、纠错次数或原石累计统计。交卷后本轮答案与成绩锁定，继续练习需明确开始新一轮。

saveReadingDraft 保存未交卷答案，不判分、不产生奖励；刷新或重启默认恢复同一轮草稿。交卷后恢复锁定答案与 paperResult；迟到的草稿保存不能覆盖已交答卷。

submitReadingPaper 先验证全部题目均已填写、选项有效且没有外来题号，再在一个事务中写入全部判分、奖励账本、锁定答卷和请求记录。请求编号与轮次、规范化完整答案绑定；重试同份答卷返回已保存结果，换答案或换轮次复用编号会被拒绝。发生中途写入错误时该篇提交事务回滚。

| 存储 | 当前职责 |
| --- | --- |
| reading_sessions | content_revision固定内容版本；paper_version=2 的新轮保存单篇草稿、结果、答案曝光和奖励动画确认；旧轮次和旧组卷记录保留 |
| reading_answers | 内部逐题结果与首次记录；新轮在交卷事务内一次写入快照，界面和 PDF 不展示首答/纠错历史 |
| reading_paper_requests | 新版完整答卷的幂等绑定 |
| reading_requests | 旧逐题提交历史，新轮不再查询或写入 |
| reading_split_migrations | 旧轮次与独立篇目的唯一迁移标记，防止重复复制或覆盖新进度 |

原有题目稳定 ID 与 reward_ledger 保持不变；拆为独立阅读不会再次重置新原石，旧轮和已有奖励继续保留。

旧五组只作为历史定义保留，不列入目录，也不再创建组卷轮次。打开独立篇目时，在同一事务中将旧组最新轮的本篇草稿、逐题记录和分数复制到新轮；只计算本篇题数，继承旧答案曝光，历史奖励动画预先确认。已有任何当前版本独立轮次时优先保留，不覆盖、不合并答案。旧原记录和账本不改写，迁移不调用发奖。

只读 reading:resolveLocation 将旧题号或全局段号映射到对应独立单元及本地段号；旧URL先规范化再打开轮次。奖励与收藏读取时只映射返回的来源位置和标题，保持账本ID、首次收藏句子、偏移和存储JSON不变。共享IPC契约共50个方法，定位接口的参数与返回值也受编译期约束。

### 奖励动画

单篇提交事务汇总实际新增奖励。paperResult.earnedCount 保留本轮实际新获数量；首次响应携带 earned，刷新或重复提交时 earned=[]。rewardAnimationPending 在有新奖且尚未确认时为 true，页面集中播放一次发放动画，再调用 acknowledgeReadingReward 持久确认。确认只更新动画状态，不产生奖励；已确认的动画刷新、重启后不重播。

### 讲解与官方双语

交卷后开放答案、选项解释、原文证据、篇章结构、重点句与词义。题库中分别记录英文和官方中文哈希，并标记经过人工逐段核对的配对；加载器校验两种原文、段号与配对状态后构造 bilingualParagraphs，不按段数相同自动猜配对。解析中的官方英文支持点词释义和收藏，收藏仍进入同一个独立词表，保存该次点击的真实原句。

提前成功导出含答案 PDF 会记录本轮已看答案；本轮仍可完成练习、照常计算得分，但不再领取新的阅读奖励。取消或导出失败不标记曝光。已经交卷结算的奖励保留，后续新轮仍按稳定题目 ID 去重。

每篇使用经来源核对的官方人物或相关地域、活动题图，按核对过的主体焦点裁剪为 1600×400；网页与 PDF 共用裁剪。具体角色故事使用该角色本人图片。阅读页允许纵向滚动，按1024宽窗口检查正文、题目、解析和弹层无横向溢出。

## 奖励

reward_ledger 保存两类历史明细：单词按学习范围+单词编号去重；阅读按稳定题目编号跨练习去重（账本保留原单元来源）。单词客观自测首次有效通过 +1；每篇阅读提交时，对每道首次有效答对的逻辑题结算 +1，汇总发放；两类全局累加，无“词数×2”固定上限。词卡主观评分不发奖，阅读结果不更改单词复习卡。

账本写入与判分同一事务完成。重复提交不重复发放，答错不扣奖励，移除收藏不删除已获原石。首页显示全局总数及两类数量，奖励明细可按来源筛选，回跳对应词书/收藏词或阅读题。

首次打开新规则时执行 independent-rewards-v2：清空旧 rewards，不结转、不按旧评分补发。学习卡片、复习日志、收藏原句与旧答题记录保留；迁移只执行一次，新奖励在重启后保留。原石清零仅属于首次启用独立奖励规则的迁移；从逐题阅读升级整篇交卷不再清零 reward_ledger。检查脚本使用隔离数据库。

## 旧收藏迁移

首次打开新版进度库时，在事务内执行 independent-collection-v1 迁移，并在 schema_migrations 中记录完成状态：

- 从旧 bookmarks 按单词 ID 去重，建立独立收藏记录。
- 复制该词最近一次复习对应的卡片、评分记录及记忆状态。
- 兼容处理旧收藏关联记录；随后新奖励迁移统一清空旧奖励。旧练习正确标记不充当来源句测试结果。
- 保留原表和各考试词书原有记录，迁移可重复打开而不重复复制。
- 旧版本没有保存来源句，因此新记录标记为待补来源，不推测或补造来源。

目前已建立这项显式迁移；更完整的内容版本迁移、导入导出和备份方案仍待完善。

## 界面

首次使用且 settings.traveler 尚未保存有效值时，选择空（aether）或荧（lumine）后进入应用；选择持久保存在进度库，导航栏头像与 About 页面可重新选择。默认伴读、缺少明确角色的回退立绘和泛指玩家旅行者的图片跟随选择；具体角色故事和明确的空/荧角色图片保持对应角色本人。切换旅行者不改变学习进度、收藏或奖励。

## 检查

scripts/check-fast.ps1 运行四组类型检查、IPC 回归、阻塞缺陷回归、复习/收藏集成回归、分级阅读回归、学习批次与剧情分类回归、立绘规则回归和应用构建。构建后执行 npm run test:collection-ui，可在隐藏 Electron 窗口验证点词收录、复习、原句测试、奖励、移除撤销和来源回跳。测试仅使用临时内容和进度。npm run check:reading-interface 检查真实阅读页面在 1024×768 / 1024×600 窗口下的整篇交卷、草稿恢复、官方双语、点词收藏、PDF 与奖励动画。npm run test:traveler-ui 检查首次空/荧选择、持久保存、重新选择及图片跟随。

准备好本地内容后执行 npm run check:practice，逐词检查考试词书出题覆盖、非空答案、原文还原、提示、单词 ID 和词书成员引用。它只读内容库，使用内存进度库。

## 路径与构建

发布版从 process.resourcesPath/content 读取内容。媒体优先读取 content/assets.asar，没有归档时读取 audio/ 和 images/。两种媒体形态应保持一致，避免旧归档遮蔽新散文件。

| 环境变量 | 用途 |
| --- | --- |
| GENSHINWORDS_CONTENT_DIR | 覆盖内容目录，包含数据库和媒体 |
| GENSHINWORDS_CONTENT_DB | 仅覆盖内容数据库路径 |
| GENSHINWORDS_USER_DATA | 覆盖用户进度目录 |

scripts/run-electron.mjs 在启动开发/预览前移除 ELECTRON_RUN_AS_NODE，避免宿主变量影响 GUI 启动。

阅读 PDF 使用 PDFKit、sharp 和已随 renderer 打包的 Noto Serif SC 字体，全离线，不依赖系统中文字体。题面先输出，解析另起页；包含本轮得分、答案讲解和官方中英原文。保存成功才记录答案曝光；提前导出后本轮可继续练习评分，奖励规则见分级阅读部分。取消或写入失败不标记曝光。原有章节/任务 PDF 保留独立实现，仍查找 Windows 本机中文字体。
