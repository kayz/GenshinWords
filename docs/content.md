# 资料来源与内容维护

## 来源

文字主要来源为 Project Amber（gi.yatta.moe）。图片从官方发布渠道查找，选用人物立绘与活动图片，不使用游戏截图。词书、释义和发音的来源分别记录如下：

| 类别 | 来源与本地记录 |
| --- | --- |
| 任务、角色语音台词、游戏书籍正文 | Project Amber（gi.yatta.moe）；正文表中保留部分来源 URL |
| 角色、美术与章节图片 | 官方发布的人物立绘与活动图片，不使用游戏截图；`content/images/art_manifest.json` 及数据库来源字段 |
| 词书与释义 | qwerty-learner、maimemo-export（上海高考）、ECDICT |
| 英美发音 | 本地词典音频；少量缺项由 eSpeak NG 生成，记录在 `content/pronunciation_sources.json` |

具体原文页面、官方图片页面、采集时间及各字段对应来源尚未完整整理。后续逐项补齐原文与图片的来源 URL；如使用其他站点资料，另行注明用途与具体页面。现有图片清单需按官方图片来源规则复核。

## 内容布局

```text
content/
  content.db                     # 当前词书、单词、例句与练习入口
  materials.db                   # 补充阅读资料、原始快照、分段与对话图
  material_matches.db            # 从本地资料生成的单词候选索引
  materials_manifest.json        # 资料、横图来源及校验清单
  material_match_report.json     # 本地匹配统计和未命中清单
  audio/                         # 单词发音
  images/                        # 角色、章节等图片
    art_manifest.json
    reading-headers/             # 官方横版原图
  coverage_report.json
  example_selection_report.json
  offline_content_report.json
  pronunciation_sources.json
  speaker_names_report.json
```

媒体也可以整体存入 `assets.asar`，替代 `audio/` 和 `images/` 散文件。当前工作目录采用散文件模式。

`offline_content_report.json` 记载当前内容批次为 11 本词书、14,285 个单词、259,150 条台词和 1,098 篇书籍正文。这些数字是现有报告的记录，更新内容后需重新生成统计。

## 版本管理与更新

Git保留代码、阅读作者JSON与配套素材、示例包和内容来源/统计JSON。数据库、音频、图片和素材归档在本机单独保存，由发布构建一并封入便携 EXE。仅克隆源码不能自动生成完整资料库，需向维护者取得同一批次的完整内容。

补充阅读资料通过 scripts/update-materials.ps1 采集和生成。每次更新使用新的带日期缓存目录；同一缓存目录用于失败重试和断点续传，已有且哈希正确的响应会被复用。缓存保存在仓库外，最终发布仅包含整理后的数据库、来源清单和合格横图。旧词库、释义与发音的历史采集流程仍需另行整理。

替换资料库时，应同步更新媒体与报告，保持单词 ID 的稳定性。现有用户进度以单词 ID 关联内容库，ID 重排可能导致旧进度指向不同单词，需要设计迁移策略。

发布前还需核对各来源的署名与分发条款；源码许可证与游戏、词典等第三方资料的许可分别处理。

## 练习覆盖验收

2026-10-21 使用 npm run check:practice 对当前 14,285 个词逐一生成并检查题目：8,621 个使用书籍原文，2,493 个使用台词原文，3,171 个使用基础拼写；全部具有非空、可判分答案和提示。该统计反映当前索引与匹配规则，不表示其余词在所有原神文本中都不存在。

英美变体在应用内按明确映射处理，原文和内容库 ID 保持不变；判分仍要求正确词形。更新内容或匹配规则后应重新执行全词检查。

## 收藏词来源

收藏只引用本地词库、本地剧情台词和分级阅读官方原文，不收录外部输入的单词或文本。原句快照存入用户进度库，内容库保持只读。收藏测试仅使用已保存的来源句；旧收藏缺少来源时明确提示补齐，不从资料库另选句子替代。

## 补充阅读资料的更新

一次完整更新通过 PowerShell 7 执行：

```powershell
pwsh -NoProfile -File scripts/update-materials.ps1 -CacheDirectory "$env:TEMP\GenshinWords-materials-20261021"
```

流程依次为：官方美术采集、Project Amber 中英文资料采集、本地整理入库、本地词形匹配、完整性检查。网络只用于维护阶段。使用已有完整缓存重建时，加上 -Offline。单独重建词形匹配索引使用 npm run content:match；核验使用 npm run check:materials。

| 工具 | 用途 |
| --- | --- |
| scripts/acquire-materials.mjs | 书籍目录与分卷正文、人物故事与台词、尘歌壶对话、任务章节 |
| scripts/acquire-official-art.mjs | 官网桌面人物美术和官网壁纸发布页 |
| scripts/acquire-version-art.mjs | 官方 HoYoLAB 壁纸专辑；核验账号 UID 1015537、认证与专辑 526679 |
| scripts/fetch-public-data.ps1 | HTTPS 下载、有限并发、重试、断点、SHA-256 与来源记录 |
| scripts/build-materials.mjs | 从缓存生成资料库和题图清单 |
| scripts/match-materials.mjs | 从本地词书与词形表生成正文命中候选 |
| scripts/check-materials.mjs | 数据库、原始快照、分段、图片、匹配版本的只读核验 |

书籍保留原有换行与空行，并记录非空原文段落及段前空行数。中英文各自分段，不按段落序号推定翻译对应。人物故事保留解锁说明和原文变体。任务与尘歌壶对话保存节点、选项、下一节点、条件和场景上下文；texts 表中的首分支预览有明确标记，完整分支仍在 dialogue_graphs / dialogue_nodes / dialogue_edges。旁白与触发台词保存在 narration_lines，阅读正文之外还保留说话人。sources 表保存采集 URL、时间、SHA-256 和压缩原始响应。

横图直接保存官方原文件，最低尺寸为 1024×480，宽高比至少 1.6。人物图记录角色关联，版本图按官方发布标题记录章节关联；活动海报、CG 待审图、竖版图和小预览图会在清单中标记排除原因。文件路径以 content/ 为基准。人物 PNG 可能带透明背景，页面可以另设背景色。

本地匹配只针对已有词库与词形表。记录正文位置，或对话节点及选项位置；不将说话人标签、格式标签和控制变量视作词汇正文。命中结果是可检查的候选，不代表词义、难度或题目质量已通过人工审核。修改资料或词形表后应重新生成索引。

补充资料与索引随 content/ 一起封入便携 EXE。资料文件和图片保持本机保存，JSON 来源与统计纳入 Git。当前分级阅读已接入69个独立练习、381道题，取材于66份不同来源文本。候选资料容量与自动分级规则见 reading-capacity.md；候选不等于已完成人工命题审核。

## 阅读内容独立发布

已完成的阅读使用`reading-library/base/`作为唯一纯数据源，包含所需官方英文／中文、映射、哈希、题目、解析和图片。独立CLI校验、打包为`.gwreading`；首次EXE内置同格式基础包，后续导入不需要替换materials.db或更新EXE，也不修改个人学习数据。采集库仍供作者选材与容量审计使用。格式和命令见[阅读包说明](reading-packages.md)。

来源网页、图片及许可记录需随内容维护；自动校验只能确认结构和完整性，不能代替人工核对官方来源、译文差异和题目质量。

## 当前阅读样例的双语校验

原五篇单篇练习分别核验1、9、10、12、7个中英文段落，共39组；首批21个独立练习核验266组，第二批19篇再核验179组，第三批24篇核验227组，总计711组官方双语。详见 reading-papers.md。对应关系经过逐段人工核对，题库同时固定英文和中文正文SHA-256，并标记双语对应已核验。运行时任一语言哈希或段落结构变化会拒绝加载，不能仅凭相同段数推断翻译对应。新增篇目需重复该审核。

阅读收藏记录真实英文来源句、句内位置、来源篇目与段号；官方中文按整段保存，不冒充逐句对齐译文。与剧情收藏共用独立词表和单词ID去重，已存在来源不会被后续点击覆盖。收藏自测继续只使用第一次收录的句子。

首次选择空／荧使用资料库现有角色卡与头像的内置副本；来源路径和校验值见 src/renderer/src/assets/README.md。此设置不改动资料库及故事原文。
