# 界面规范与检查

## 旅行者与配图

首次进入必须选择空或荧，选择保存在本机进度库的 settings.traveler。顶部头像按钮与关于页均可重新选择；切换立即更新当前画面，重新打开仍使用已选旅行者。

复习词卡使用人物立绘，适用于考试词书和收藏词。例句切换只在显示释义后开放，立绘和角色名随当前例句同步切换：

- 原说话人在 speakers 中有 image_kind=portrait 时，使用角色自己的立绘。
- 泛指 Traveler／旅行者的立绘、头像跟随用户选择；明确写作 Aether／空、Lumine／荧的故事角色保留其身份。
- 无来源、无立绘或图片读取失败时，使用随界面打包的所选主角伴读立绘，不将主角标作原台词说话人。
- 收藏词仍使用真实收录来源，切换旅行者不改写任何来源快照。
- 剧情封面保留来源图；角色语音章节改用本人官方横版立绘，空、荧保留各自身份，按真实图片尺寸和人物焦点裁成4:1，保证脸部可见。
- 阅读头图使用对应故事角色或相关地域主题的官方横图；角色语音阅读使用本人立绘，按人物焦点裁成4:1，网页与PDF共用同一裁剪。

内置空／荧立绘及头像清单、哈希和来源库路径见 src/renderer/src/assets/README.md。

## 独立阅读与讲解

阅读目录按级别列出独立篇目，显示题型、词数、题数及建议用时，不设置整卷入口。每个页面只含一篇材料与对应题目，包括标题、4:1题图、正文、必要普通难词括注和“答题区”；不展示能力目标、实现细节、首答/纠错记录或奖励明细。原神专名只在解答区解释。

已提交过整篇的目录项显示蓝色“✓ 已做过”；历史任一轮全部答对则改为香槟金“✦ 已全对”，图形和文字共同区分状态。草稿不算完成，重开不会清除历史标识。讲解顶部与底部均可进入“下一篇阅读”：当前级别按顺序循环，跳过已全对篇目，仍可通过目录手动重读；没有其他待挑战篇目时显示派蒙提示，不自动换级别。

每篇独立保存草稿；本篇全部完成后一次提交和判分，不必完成其他篇。每题1分，结果只显示“本轮得分”。本轮新获原石通过一次动画发放，动画结束或关闭后确认已显示；刷新可恢复尚未展示完的奖励，不重复记账。

交卷后展示题目答案与解析、逐段完整英文和已核验的官方中文译文、文本解析和“单词解释”。在英文原文中点词，可查本地词典、播放本地发音并加入独立收藏词表；后端从原文提取收录句和词的位置，不接受外部单词或文本。

PDF保留浅色纸面、中文字体和4:1题图，将题面与解析导出为一份文档。提前导出包含答案的PDF后，仍可提交本轮练习成绩；该轮按参考答案练习处理，不再取得阅读奖励。成功交卷后才自动打开网页讲解。

题目、结果与奖励互不跨篇混合；切换篇目不提交其他篇，不覆盖其草稿，提前导出仅影响当前篇当前轮。

提示语以简洁的派蒙口吻面向学习者，例如“提瓦特大陆有太多故事”“背单词累了吗？来读读故事吧，答对题有奖励哦。”不在阅读题面解释开发设计。

## 字体与颜色

| 用途 | 值 |
| --- | --- |
| 应用背景 | #101c2b |
| 面板背景 | #17283c |
| 正文 | #f3ead8 |

标题、词头和主要按钮使用随应用提供的 Noto Serif SC Medium 2.003；正文优先使用 Windows 中文界面字体，英语原文使用 Georgia，音标使用支持 IPA 的常规字体。字体无需联网或额外安装，来源和授权见 src/renderer/src/assets/fonts/README.md；关于页面包含 SIL OFL 授权全文。

阅读纸面采用浅色背景、深色正文；选择控件与解析保持清楚的前景/背景对比。普通文字目标至少4.5:1，焦点使用可见轮廓，减少动画偏好下使用静态奖励反馈。

## 窗口与滚动

默认外框宽度1024，并按屏幕工作区缩小初始与最小尺寸。页面和操作区自然换行，不以隐藏横向溢出掩盖内容。

- 阅读正文、题目、解析、收藏与关于页允许正常纵向滚动。
- 复习详情固定立绘区域，长释义与台词在卡片内滚动，评分按钮保留在可见操作区。
- 首次选择弹层按窗口高度限制并可滚动，支持键盘焦点；已有选择时可取消重选。
- 720px以下采用单列布局。

## 可复现检查

先用 PowerShell 7 运行 scripts/check-fast.ps1，完成类型、IPC、服务回归、内容与构建检查。构建后运行：

- npm run test:collection-ui：收藏、复习、原句测试、撤销和来源回跳。
- npm run test:traveler-ui：首次选择、即时图片切换、重启保存、剧情头像和关于页重选。
- npm run check:interface：真实本地资料的主要页面与立绘，覆盖1024×768、1024×600、1008×730、819×600。
- npm run check:reading-interface：五级样例整篇答题、交卷讲解、双语点词收藏、奖励确认、PDF及边界布局。
- 界面脚本可用 --output <绝对目录> 将截图和report.json保存在仓库外。

检查使用临时进度库，不改变用户学习记录。程序检查包括横向边界、文字和输入控件对比度、离线资源、立绘、滚动、页面错误及网络请求；截图还需人工查看，发布前仍需在真实显示缩放设置与屏幕上验收。
