# 本机资源目录

应用 1.2.0 在“内容管理”中增加目录选择和运行时载入。资源目录不存个人学习记录；选择目录不会覆盖 progress.db、收藏、成绩或原石。

## 最终用户操作

1. 打开“内容管理”，点击“选择资源目录”。
2. 选择解包资源所在目录，或保存成品内容包的目录。
3. 查看基础资料统计、各包名称与版本、依赖和错误。
4. 点击“确认载入”。通过检查的内容在本次运行中启用，之后返回首页选择词书或进入阅读。
5. 软件保存目录路径；增加包或更换文件后，点击“重新扫描”并再次确认。目录不会被后台监控，也不会联网下载内容。

取消预览不会更换当前资料。某个包失败时单独报告，其他符合要求的包可继续载入；原有可用版本保留。

## 解包目录：直接读取媒体

选择同一根部包含 content.db、materials.db、images/ 和 audio/ 的完整目录，并保持数据库引用的相对路径。媒体目录即使没有引用也应保留；不以 assets.asar 代替松散文件。也可选择其上一层，软件会识别标准 content/ 子目录。

软件以只读方式校验数据库、原有编号和引用资源，再准备本机数据库快照与派生索引。媒体保留在原位置，不复制整套图片和发音。外部文件不能是越界路径或指向外部的链接。

WAL 模式数据库为保护原目录，会在受限内存中校验；单库超过 256 MiB 时拒绝载入。作者应先在副本完成 checkpoint 并转换为 DELETE 日志模式后再提供，不要让学习软件直接改写原资料。普通 DELETE 模式数据库不受这个 WAL 内存上限影响。

原目录必须在使用时可访问。移动、拔出磁盘或改动文件后，页面可能报告资源不可用；重新选择完整目录并确认。不要直接在使用中的原目录覆盖数据库或媒体，应使用另一目录准备好完整的新版本再切换。历史数据库快照不等于媒体备份。

无元数据的旧布局显示“版本未登记”。可以在根目录提供 UTF-8 的 resource-manifest.json，内容为 {"name":"基础资料名称","version":"1.0.0"}，供页面显示；软件仍会核对实际文件摘要。这个标签不能代替具名包的版本依赖。需要完整兼容要求、依赖和正式分发时，请制作 .gwcontent 基础包。

## 包目录：校验后载入缓存

支持 .gwcontent、.gwwords 和 .gwreading。把包放在所选根目录，或两层以内的标准 content/、reading/、word-books/、packages/ 子目录中。每次最多扫描 4,096 个目录条目、128 个包和 32 GiB 包文件；超限会提示，请把所需内容放入较小的专用目录。

预览先检查容器、完整性、版本与依赖；确认时再次核对，按基础包、依赖和增补内容的顺序准备和载入。数据库语义、编号和词表匹配等检查会在实际准备时执行。已经过预览的文件如果被替换，不会沿用原确认结果。

包会写入受管缓存，后续使用不依赖原下载文件。记住包目录路径是为了下次扫描，不会让用户的作者文件被修改。同一包同版本同内容重复载入无副作用；更新须提升版本号，冲突和降级会拒绝。

同一目录中同时有可用解包基础资料和完整基础包时，优先使用解包资料，并显示跳过基础包的原因。若要改为包内基础资源，选择只含所需包的目录；新基础包成功启用后替换原基础目录，失败则保留原状态。只载入词书、素材增补或阅读包时保留当前基础资料。单文件导入基础包不会自动取消已选择的解包目录；要切换基础来源，请使用包目录的确认载入流程。

## 存储、历史与恢复

Windows 默认缓存及目录配置在 %LOCALAPPDATA%/GenshinWords/，个人学习记录仍在 %APPDATA%/genshin-words/。阅读包及历史内容沿用原阅读存档目录。使用 GENSHINWORDS_USER_DATA 等隔离路径时，测试文件写入隔离位置。

更新不会把原卡片编号或英文来源转给其他内容。阅读包升级保留未完成轮次的内容快照，历史成绩对应原版本，奖励按稳定逻辑题号去重。包目录和基础目录分别记录；缺失的目录在页面报告，不影响已缓存并可独立使用的包。

换机时备份两处数据目录，并保留直接读取的外部资源。目录路径不同则在新电脑重新指定。普通卸载程序、删除下载文件和清理个人学习记录是不同操作；软件没有包卸载或旧版本自动清理界面。

恢复缓存后，软件按新账户的缓存位置寻找数据库快照，不沿用旧电脑的快照绝对路径。原目录移动，或快照元数据丢失、损坏时，只要原数据库快照仍可读取，就可以重新选择完整目录恢复。若连旧数据库快照也已遗失，软件会给出需恢复的 content.db、materials.db 路径；先从备份或旧版完整资料恢复这两个文件，再重新指定目录。这个限制用于核对旧词条和台词编号，请不要通过删除学习记录绕过。

## 制作者与维护者

内容制作、独立版本和离线发布命令继续使用[内容包说明](content-packages.md)、[阅读包说明](reading-packages.md)。成品包目录不需要注册 TypeScript 文件或重新构建 Electron。

检查使用隔离数据目录。目录校验和热载入回归命令：

~~~powershell
npm run test:resource-directories
# 完成build后运行实际Electron界面检查，输出到指定目录
npm run check:resource-directories-interface -- --output C:/temp/GenshinWords-directory-check
pwsh -NoProfile -File scripts/check-fast.ps1
~~~

程序安装包不包含大型基础素材。发行时在独立下载地址提供成品包或完整解包资料，并在说明中提示首次进入软件选择资源目录。本项目现有资源不在 GitHub 仓库或 Release 分发。

本版本的测试范围、安装包摘要及未验证事项见[资源目录验收记录](resource-directories-verification.md)。
