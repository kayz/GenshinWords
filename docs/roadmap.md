# 后续开发事项

当前已拆分单词学习/客观自测与分级阅读，五档共69个独立阅读练习、381题，保留原题目编号。阅读采用整篇交卷、每题1分，只展示本轮得分；草稿、锁定答卷、幂等结算及奖励动画确认已接入。解析提供官方英中原文、点词释义和本地词收藏，与剧情共用同一个独立收藏表，测试仅用首次收录原句。两类奖励全局累计，独立篇目改版保留已有新账本。阅读支持4:1官方人物题图和离线PDF。

阅读现已拆为独立自包含`.gwreading`包：JSON与素材制作、CLI校验／打包、离线导入、版本存档和冲突检查均已接入；旧轮次固定内容版本，补充包不要求重发EXE。制作与版本规则见reading-packages.md。

首次使用可选择并持久保存空或荧，导航栏与 About 可重选；默认伴读及泛指旅行者图片跟随选择，具体角色故事保持角色本人。公开 IPC 使用统一类型定义。以下事项留待后续讨论与开发：

- 阅读校准与扩充：按上海中高考真题和学生试用继续校准档位、题量及干扰项，增加应用文、说明文与观点材料；专业英语、考研、雅思和托福不建设独立阅读路线。新增篇目通过纯数据阅读包发布，沿用官方英中核验、稳定题号和单篇提交规则。
- 单词自测编排：目前按词轮转并推荐每组5–8词穿插回测，后续讨论自动组题、薄弱点回测，以及阅读后再练的间隔调度。阅读按单篇提交判分，当前重新练习需显式开新轮，无固定等待锁定。
- 内容维护：补齐 Project Amber 原文与官方图片的具体链接和许可记录，完善资料库生成流程、双语配对记录及内容版本标识。
- 发布验收：在无开发环境的 Windows x64 机器完成断网验收，记录 portable 启动及解压时间，并验证首次角色选择、阅读、收藏、PDF与进度恢复。
- 进度保护：完善 schema 版本迁移、导出导入与安全备份，处理资料库 ID 变动。不得在后续界面或阅读流程升级中重复清空已建立的新奖励账本。
- 收藏管理：在两类来源共用词表、真实原句、来源回跳与移除恢复基础上，讨论批量操作和更多筛选；继续只收本地词，保留首次来源。
- 复习体验：讨论每日新词量、会话上限和短期到期提示；保持阅读得分与词汇卡片分开。
- 类型与边界：继续收紧主进程数据库与 PDF 内部类型，补齐运行时入口参数及历史数据校验。
- 阅读包管理：后续讨论发布者签名、包卸载与历史存档清理；当前不自动删除仍可能被旧成绩或收藏引用的版本。
- 性能：检查大词书选题、主进程同步查询、媒体缓存、长篇双语解析与 PDF 大章节导出。
- PDF：阅读已内置中文字体、分页和官方双语，后续统一原有剧情导出的字体与词形高亮。

上述事项为后续工作；当前学习、阅读与收藏规则见 architecture.md。完成前执行 scripts/check-fast.ps1，构建后可运行 npm run check:reading-interface、npm run test:collection-ui 和 npm run test:traveler-ui 验证页面流程。
