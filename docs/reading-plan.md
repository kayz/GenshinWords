# 阅读分级与题型设计

## 范围与状态

核心用户为上海中学生。内容建设优先顺序为上海中考、上海高考，再延伸到大学英语四级和六级；初中基础阅读提供入门支持。全国中高考词书可作为补充参照。专业英语、考研、雅思和托福不建设独立阅读路线，其中自然出现且适合本地语境的词汇可作为随文拓展。

产品目标是通过原神语料进行语境记词与阅读训练。上海中高考采用独立的考试参照，不用地区名称直接换算难度；上海高考与四级的文章允许交叉适配。

本文件记录已确认的范围和待校准的分级设计。2026-10-23 已接入五档共69个独立阅读练习、381题，来自66份不同来源文本。每篇独立保存草稿、提交、判分、查看解析和领取奖励，不设置整卷；题面与讲解由人工整理并随应用离线发布，每题1分，提供经逐段核对的官方英中原文。详细题型、篇目、用时和验证规则见 [独立阅读篇目与题型](reading-papers.md)。这些内容尚未通过真题等值对照和学生试用，不代表完整题材覆盖。

## 训练档与选材

下表篇幅是产品首轮选材参数，不是官方考试篇幅要求。短文也可能包含高难度论述，长文也可能语言简单；篇幅不足时可按内容完整性保留，不用拼接无关文字补足长度。

| 训练档 | 初选篇幅（英文词） | 优先材料 | 能力与题型 |
| --- | --- | --- | --- |
| 初中基础 | 30–100 | 日常角色台词、短对话 | 事实定位、简单指代、语境词义；每单元 2–3 题 |
| 上海中考 | 150–300 | 日常人物故事、完整小事件、简短说明或告示 | 细节、主旨、简单推断、事件顺序；搭配完形、首字母填空或证据选择，每单元 3–5 题 |
| 上海高考 | 300–500 | 有转折和人物动机的故事、解释性段落、观点段落 | 细读选择、观点与态度、段落功能、语篇选词、完形与句子衔接；每单元 4–6 题 |
| 四级 | 350–600 | 结构清晰的完整故事、说明和观点文本 | 仔细阅读、同义转述、选词填空、段落信息匹配；每单元 4–6 题 |
| 六级 | 500–800 | 具有抽象表达、多层逻辑或完整论述的文本 | 隐含意义、论述结构、观点归属、语气、跨段信息整合及适用的匹配题；每单元 4–7 题 |

上表是单篇细读的初选参数；独立练习另含短应用文、完形、句子回填、15选10及约1000—1400词的自然段匹配，不能按同一篇幅区间限制所有题型。每份材料可以有多个适用考试标签。上海高考与四级尤其需要按实际文本和设问交叉判断，不建立固定的一档对应一个更高考试的关系。

阅读理解为单元主体，通常只配少量目标词题；不把每篇都组织成一组挖词题。题数根据可独立考查的信息量确定，不能用重复设问补足。

## 分级方法

### 五项共同判断

1. 词汇负担：以上海中考、上海高考词书为主要参照，四级和六级以基础词汇合并去重后的集合补充。明确本项目导入词书不是官方完整考纲；词书命中率也不是学生熟词率。正式筛选前补齐明确的英美拼写映射，避免把拼写差异当成高级生词。
2. 句法负担：记录平均与最长句长，检查嵌套从句、非谓语、插入、倒装、虚拟表达和指代链。句长或可读性公式仅作筛选线索。
3. 篇章负担：检查是否只需定位事实，还是需要跨句、跨段处理因果、对比、转折、主张与论据。
4. 背景负担：标记人物、地名、游戏术语和剧情前情。少量必要背景可用中文提示；靠长篇前情才能理解的材料退出首批。
5. 题材与完整性：检查是否自洽、有没有足够信息形成唯一答案、是否适合上海中学生。人工语言、占位、残缺文本和依赖未展示分支的材料不进入首批标准阅读。

分级选材优先保留完整选段和原文措辞，通过篇目、题量和设问深度适配学生。当前阅读题面展示英文正文与全部题目，按题型提供挖空视图；低阶仅对可见的非目标普通难词加括号注释，专名、目标词和文本理解放在交卷后的讲解，不逐题提供解题线索。

### 题目难度单独标注

材料记录适用档、辅助档和判定理由；每道题另记技能、推理范围和提示程度。同一材料可供不同水平训练，但简单事实题答对不表示学生已具备理解全文的能力。

首批为试行课程，已完成原文、答案证据和官方中英段落配对核对；真题等值对照与学生试用尚未完成。后续根据正确率、用时、查词和反馈校准，不用假定正确率阈值声称等级已验证。维护数据中的背景、技能和提示字段不直接展示为题面备课说明。

## 单元组织与本地判分

每个学习单元只含一篇阅读，独立配相关官方横版题图、英文正文、适配的题型与作答后讲解。完形、选词和句子回填采用经源文偏移校验的挖空视图；完整英文与官方中文放在讲解。初中／中考正文对可见普通难词提供括号释义，排除挖空词与受限填答目标，不在题面解释专名或展示完整词表。阅读理解与词汇学习分别记录；答对主旨题不会把全文单词记为掌握。

本篇全部作答后一次提交，答案和判分在同一轮锁定。每题1分，页面仅展示本轮 score/maxScore，不展示历史首答、纠错或原石统计。未交卷草稿自动保存，刷新或重启恢复同一轮；想再练需明确开始新一轮。主进程在一个事务中判完整答卷、保存结果和结算新奖励，完整答案与轮次绑定请求编号，重试不重复发奖；未填完或含外来题号的答卷不能部分提交。

| 题型 | 使用条件与判分设计 |
| --- | --- |
| 单项选择、事件排序、段落信息匹配、证据定位 | 本地确定性判分；每项有答案与证据。语义匹配题的错误项应与原文相关，不能只靠词面重复判断 |
| 选词、完形、首字母与句子回填 | 先检查答案唯一性、语法和篇章线索。首字母不自动保证唯一答案；合理替代不能排除时修改或撤下该空 |
| 限定原文的信息提取 | 明确词数、抄写范围或首字母，预先收录可接受变式；只判受限答案，不将其称为开放语义判分 |
| 简答、概括和观点解释 | 首轮用证据选择、要点勾选等可离线判分的训练变式；开放式表达保留要点与示范答案供自查，不靠原句字符串相等判错，不据自查结果自动授予掌握奖励 |

上海中考的图文阅读需要真实的信息图、路线或信息表。现有官方插画只承担题图功能，不能充当有信息证据的路线图。只有本地原文确有时间、路线、条件等事实时，才可整理成明确标注的训练图表，并保留事实映射。

长篇匹配要求有足够且可区分的自然信息段。不能把数句台词或无关角色语音拼在一起，制作成十题的伪长篇匹配。短材料可以制作少量匹配的训练变式，注明不等同完整考试题组。

阅读信息提取题允许回到完整正文定位，使用改写题干和限定作答范围；这不作为单词掌握证明。词汇拼写自测收起词卡答案；当前完形、首字母、选词和句子回填已提供独立挖空视图，不在答题区重复展示还原原文；共用选项池与A—J自然段组完整呈现。当前页面不设置逐题检查、提示和纠错流程。

题目在维护阶段制作、审阅并随离线内容发布，运行时无需在线生成。

解析逐段展示官方英文与中文。题库同时记录两个版本的正文哈希和人工配对标记，运行时验证原文与段号后使用，不因段数相同自动猜测对齐。解析英文可点词查询本地释义并加入原有独立收藏词表：只收本地词库已有词，保存点击当时的真实英文句子及句内范围；对应官方中文整段作为参考并明确标注。剧情与阅读两种来源按同一 wordId 去重，保留第一次来源。收藏词测试继续仅用该次收录原句，不另找阅读材料。

## 单词学习、阅读训练与原石（已确认）

本节规则已接入当前实现。单词学习与阅读训练分成两个阶段，建议先背单词再阅读；各自记录结果，不再要求“记忆评分与对应单词阅读测试同时通过”才获得奖励。

### 两类奖励与总数

| 来源 | 发放条件 | 数量 |
| --- | --- | ---: |
| 单词自测 | 学习后首次有效通过该词的客观自测 | +1 |
| 阅读答题 | 整篇交卷时，对每道首次有效答对且尚未获奖的逻辑题统一结算 | 每题 +1 |

原石总数为两类累计数量之和。阅读题数不与单词数一一对应，不设“必须恰好翻倍”的限制，也不再用词书单词总数作为全部原石的上限。

奖励按学习项去重：词汇使用学习范围与单词，阅读使用稳定题目编号。刷新、重复提交或从不同入口打开同一道题，不应重复发放。单词自测通过时反馈奖励；阅读在整篇交卷后汇总本轮新增数量，集中播放一次发放动画。结果记录 earnedCount 与动画确认状态，刷新和重试不重新发奖；播放确认持久保存后，重启不重播已确认的动画。完整篇章解析在交卷后开放。

### 旧原石处理

实施新规则时清空旧原石，从新规则开始计数，不迁移、不结转，也不根据旧记忆评分或旧测试结果自动补发新原石。清零范围仅限奖励；词汇学习进度、复习安排、收藏及收录原句另行保留。

清零仅由首次启用独立奖励规则时的显式迁移执行；后续重启不清空新奖励。从逐题阅读升级整篇交卷保留现有 reward_ledger，不再次清零，不根据旧记录补发。旧逐题轮次和请求历史保留，默认打开当前单篇轮次。开发检查使用隔离进度库，不直接改动实际用户进度。

### 来源明细

首页和原石页展示两类原石的累计总数；详情提供两类数量及来源筛选。每笔记录至少显示：

- 来源类型：单词自测或阅读答题。
- 学习内容：单词与释义，或篇章标题、题号与题型。
- 所属资料：词书／收藏词表，或阅读单元与训练档。
- 获得时间与数量（+1），以及返回对应学习内容的入口。

### 自测、整篇结果与长期记忆

单词部分增加客观自测，使用英文认义、必要的词义限定和重点词拼写等形式；答题时收起答案。可先按每组 5–8 词试行穿插回测，该数量为待校准的产品参数。

单词自测一次通过显示为“本轮通过”，后续继续按记忆曲线复习。阅读内部保留单篇结果及历史答题快照，页面与 PDF 不展示历史首答和纠错计数；本轮得分只由本次提交的正确题数确定。阅读答对不会将全文词汇标为掌握，答错也不会清除词汇学习成果。

答错不扣原石。本篇提交后本轮答案锁定，重读后可显式开新轮；新轮答对之前未获奖的题可领取一次奖励，已获奖题不会重复领取。提前成功导出含答案 PDF 后仍可在本轮练习并计算得分，但本轮不再领取新的阅读奖励；取消或导出失败不标记曝光。交卷后的完整讲解不改变已经结算的成绩与奖励。没有固定分钟等待锁定，更细的间隔调度留待试用校准。

收藏词自测仍仅使用收录时原句，不因阅读模块新增其他句子。

## 后续落地顺序

1. 将上海中高考的代表性阅读材料与本地候选按同一表记录词汇、句法、篇章、背景和设问要求；确认可重叠的边界。外部考试材料只作校准参照，不作为学习资料导入。
2. 补齐筛选索引中的明确拼写变体、专名与游戏术语标记；使用自动指标缩小候选，再逐篇审核。自动指标不直接给出正式考试等级。
3. 维护已接入的五档独立篇目，继续拓展叙事、说明、应用文与观点文本的题材覆盖。每道题核对答案唯一性、证据和干扰项；短材料不重复设问，同一源空位跨卷复用时沿用同一稳定逻辑题号。
4. 扩充现有离线题库与索引，沿用单篇提交契约，记录来源版本、材料 ID、选段范围、英文及中文哈希、人工段落配对、题图、词表、题目、答案、证据与审核状态。
5. 任务对话先选择可解释的完整路径，保存节点和选项；不使用未核对的首分支预览拼接题。保留原始分支，发现条件不明、回环或外部跳转时先人工处理。
6. 小范围学生试用后调整提示、题量和材料标签；保留旧词汇复习覆盖与收藏原句规则，分别记录阅读与词汇的学习结果。
