# 独立阅读篇目与题型

## 产品规则

2026-10-22：阅读以独立篇目为单位，按级别选择；不设置整卷。每次打开只呈现一篇材料及其题目，完成本篇后单独提交、判分、查看解析和领取奖励。篇目可以采用不同题型，同一篇内不逐题判分。

现有内容共69个练习、381题，来自66份不同来源文本。原五篇25题与首批21篇127题的编号保持不变；第二批新增19篇100题，第三批新增24篇129题。相同文本用于不同档位或题型时计为不同练习，统计语料时去重。

## 正式考试参照与边界

- [上海2025年中考英语官方评析](https://www.shmeea.edu.cn/page/08000/20250615/19514.html)强调实际情境中的信息处理、上下文补全和事实／推断／概括。这些练习采用应用阅读、完形、首字母与信息提取组合；原神宣传册不能替代评析中的路线图、图标和信息表。
- [上海2019年初中英语评价指南](https://www.shmeea.edu.cn/resource/upload/www/201812/07150630ozpf.pdf)提供历史评价参照；具体年份结构仍需结合当年的官方说明，不把旧指南标为最新考试规定。
- [上海2025年高考英语官方评析](https://www.shmeea.edu.cn/page/02200/20250609/19465.html)强调应用信息、语篇理解和观点梳理；[2017年官方评析](https://www.shmeea.edu.cn/page/08000/20170611/9124.html)明确说明六选四句子衔接形式。这些练习据此选择题型，篇幅和题量属于产品训练安排。
- [中国教育考试网CET笔试结构](https://cet.neea.edu.cn/html1/folder/16113/1586-1.htm)列明四、六级阅读均为选词10题、匹配10题、仔细阅读10题，共40分钟。[2016修订版官方大纲](https://cet.neea.edu.cn/res/Home/1704/55b02330ac17274664f06d9d3db8249d.pdf)另提供篇幅与组织参照。这些练习采用15选10、长篇匹配及两篇各5题细读；部分原文比参照篇幅略短或略长，保留完整原文，不为凑字数改写或拼接无关段落。

所有阅读练习尚未经过真题等值或学生试用校准。原神语料的文体、专名与叙事背景有其局限，不能据此声称完整覆盖现实生活、科技、社会和学术主题，也不建设英专、考研、雅思或托福的独立阅读路线。

## 数据与来源核验

全部69篇的唯一作者源已迁至`reading-library/base/units/*.json`，官方双语在`sources/`，题图在`assets/`并由`images.json`记录出处。旧TypeScript内容模块已移除，历史目录以引用式legacy-groups.json保留编号兼容，不复制题目，也不提供组卷入口。独立包制作、校验、导入与版本规则见[阅读包说明](reading-packages.md)。

每篇保存原始materialId、完整英文和官方中文正文的UTF-8 SHA256、人工双语核对标记、选取的英文源段及对应中文源段列表。允许一段英文对应多段中文，不因段数相同就推定翻译对齐。运行时验证原文哈希、源行顺序、选择范围和配对。

空位保存源段内UTF-16 start/end和expectedText；运行时校验精确匹配、无重叠、所属题号和标准答案。题面保留官方原文或经校验的挖空视图，完整英文与官方中文只放在讲解和PDF解析中。网页与PDF的P号均从本篇P1开始，证据、重点句和收藏返回位置使用本篇编号。A—J仅用于匹配题的自然组。

原五篇已核对39组双语，首批新增21个练习核对266组，第二批19篇核对179组，第三批24篇核对227组，合计711组。新篇仍需逐篇核对来源、段落对应、答案唯一性和干扰项；资料容量自动筛选不能替代这些审核。

人物故事和角色语音使用本人官方横版立绘；其他篇目使用经核对的相关官方地域或活动插画，按主体位置裁为1600×400，网页与PDF共用。不使用游戏截图。

## 作答、奖励和导出

草稿、提交结果、答案曝光、重练和奖励动画以单篇轮次保存。每篇所有题目完成后一次提交，在同一事务里判分、锁定本轮答案和结算该篇奖励；其他篇不受影响。界面只展示本轮得分，不显示历史首答和纠错计数。

稳定题号跨练习只获奖一次。拆分现有篇目不清空原石、不重新补发历史奖励。旧链接、旧作答和旧答案曝光按兼容规则处理；不把不同篇的分数混为一份结果。

初中和中考题面仅为可见普通难词添加必要括号释义，排除被考查的空位词、受限填答目标与可接受变式。专名解释放在解答区。提交后提供答案依据、错项讲解、官方英中原文、文本结构、重点句和单词解释；点词查词与收藏仍只引用本地资料。

PDF按本篇导出：题面在前，答案和解析另起页，保留内置中文字体和4:1题图。提前成功导出含答案PDF，只影响本篇当前轮次的奖励资格，其他篇不受影响；取消和失败不标记曝光。

## 资料扩充与检查

可供扩充的本地材料量、分级筛选口径和待审核限制见[阅读资料容量盘点](reading-capacity.md)。候选篇数与已编写练习数量分别记录，跨级复用不重复计入语料总量。

`npm run test:reading`核验独立目录、段落与空位映射、单篇草稿和提交幂等、奖励去重、旧版进度兼容和来源定位。`npm run check:reading-interface`以隔离进度库核验真实Electron页面的独立作答、解析、收藏、奖励、PDF和1024宽显示。PDF视觉样例放在仓库外，不随内容库提交。
